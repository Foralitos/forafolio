# design-sync notes — forafolio

This repo is a **Remix portfolio app**, not a conventional component library. It is
synced via the package shape in **synth-entry mode** (no `dist/`, no shipped
`.d.ts`). The bundle is built from `app/components/*` directly.

## Build setup (re-sync essentials)

- **Self-symlink required.** PKG_DIR resolves to `node_modules/forafolio`. There is
  no published package, so create the symlink before building:
  `ln -sfn "$(pwd)" node_modules/forafolio`. It's gitignored — **recreate it on
  every fresh clone**, or the build dies with `ENOENT node_modules/forafolio/package.json`.
- **CSS is compiled, not shipped.** `cfg.buildCmd` = `bash .design-sync/build-css.sh`
  compiles `app/tailwind.css` (Tailwind, scanning `app/**`) into
  `.design-sync/_compiled.css` (gitignored, regenerated) and prepends the Press
  Start 2P webfont `@import`. `cfg.cssEntry` points at that file. Re-run the build
  command whenever app Tailwind classes change.
- **Component discovery**: synth-entry scans PascalCase value exports under
  `cfg.srcDir = app/components`. `~/` imports resolve via `cfg.tsconfig`.
- Build/validate run with `--no-render-check` (see below). Driver: `resync.mjs`
  with `--no-render-check`, no `--remote` on a first sync.

## Fonts

- PP Neue Bit (`font-neuebit`) and PP Mondwest (`font-mondwest`) ship from
  `public/fonts/*.otf` via `cfg.extraFonts`.
- **Press Start 2P** (`font-pixel`, used by NPCDialogBox) is an OFL Google webfont
  the app loads at runtime — handled by `cfg.runtimeFontPrefixes` + the `@import`
  build-css.sh prepends. Needs network at render time.

## Previews

- **Authored (4):** PrimaryButton, SecondaryButton, NPCDialogBox, ScrollDownIndicator.
  NPCDialogBox uses an inline SVG data-URI avatar (the app serves a PNG at runtime).
- **Floor cards (6, by design):** Hero, About, Contact, Navbar, Footer, Projects —
  full-page landing singletons that read `useCDMXTime`, render full-bleed, and
  reference unshipped `/public` images (`Projects` also needs a `projects` array).
  Authorable on any later re-sync if wanted.
- Card overrides: NPCDialogBox `column`, ScrollDownIndicator `single` (it's
  `position: fixed`).

## Known render warns (triaged, not new)

- `[FONT_REMOTE] "Inter"` — benign; Inter is the default system-stack sans.
- `[RENDER_SKIPPED]` — no browser installed this run; render check was skipped and
  verification was **human review** of `ds-bundle/.review.html`. Install
  playwright+chromium for an automated gate on a future sync.

## Re-sync risks (watch-list)

- The `node_modules/forafolio` self-symlink must be recreated on a fresh clone.
- `_compiled.css` is regenerated by `buildCmd`; a stale one silently ships old
  styles — always run the build command first.
- NPCDialogBox / ScrollDownIndicator previews depend on in-view + scroll + fixed
  positioning; they look right in a real browser, less so in a static screenshot.
- Press Start 2P loads from Google Fonts at runtime (network dependency).
- Floor-card sections render functional but with broken `/public` image refs —
  expected, not a regression.
- No automated render verification was performed this run (no browser).
