# forafolio

Portafolio personal de Fora — landing con tema día/noche según la hora de CDMX, blog y admin propio.

Next.js 16 (App Router) · JavaScript · Tailwind 3 · MongoDB/Mongoose · NextAuth v5 · Cloudinary · Vercel

```bash
yarn install
cp .env.example .env   # llena las llaves
yarn dev
```

Las convenciones y decisiones del proyecto están en [`CLAUDE.md`](./CLAUDE.md).

La versión anterior (Remix v2) vive en la rama `remix-legacy`.
